## Overview

This repository contains my personal portfolio website. The interface presents selected public and private work through custom project visuals, category filters, accessible detail dialogs, responsive layouts, and dark or light themes.

## What it does

| Area | Details |
| --- | --- |
| **Project storytelling** | Twenty-three curated projects with links and private case-study paths. |
| **Accessible interaction** | Keyboard-aware navigation, focus management, reduced-motion support, and readable contrast. |
| **Responsive design** | Layouts and project visuals adapt from desktop to mobile without a separate application. |
| **Static delivery** | The production build needs no database and can deploy to GitHub Pages or other static hosts. |

## Repository map

| Path | Purpose |
| --- | --- |
| `src/App.tsx` | Page structure and interactive behaviour. |
| `src/data/portfolio.ts` | Portfolio content, projects, education, journey, and awards. |
| `src/components/` | Reusable project artwork, brand icons, and reveal behaviour. |
| `src/styles.css` | Theme tokens, layouts, responsive styling, and animation. |
| `public/` | Portraits, social artwork, manifest, sitemap, and robots file. |
